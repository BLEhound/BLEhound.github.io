# 射频测试台（附加用途）

由于 BLEhound 本身就是一个具备可控射频和被动抓包通路的完整 BLE 端点，同一套硬件还可兼作一个**低成本、相对量测的 BLE 射频测试台** —— 适用于固件射频回归、批次一致性以及产线 go/no-go 筛选。

!!! warning "它是什么 —— 又不是什么"
    这是一种**相对／黄金参考基准（golden-referenced）**的量测，适合研发和产线分选。它**不是**经过校准、可溯源、认证级别的量测。绝对功率（dBm）、频率精度（ppm）、调制质量以及邻道功率是否达标，都需要仪器（SDR、频谱分析仪，或一台真正的 BLE 测试仪）。参见下文的局限。

## 核心思路：信令模式，而非 DTM

「信令（signaling）」测试仪扮演一条**真实** BLE 连接中的对端，因此被测设备（DUT）运行的是它正常的量产固件 —— 无需 Direct Test Mode（直接测试模式）。

- **发射侧指标**来自对 DUT 真实数据包的分析：相对功率（由 RSSI 得出）、数据包时序以及错误率。
- **接收灵敏度**利用 BLE 协议自身的确认机制：一个配套的 central 逐级调低其发射功率，同时 BLEhound 在空口监听 DUT 的 `NESN` 确认。未被确认的下行数据包所占比例即为 DUT 的接收 PER —— DUT 上无需任何测试固件。

## 你能测量什么

| 指标 | 仅用 BLEhound | 说明 |
|---|---|---|
| 相对发射功率 | ✅ | 逐信道 RSSI；相对黄金样机可捕捉 PA／天线／匹配故障 |
| PER / CRC 错误率 | ✅ | 真实流量下的链路质量 |
| 接收 PER → 相对灵敏度 | ✅ | 配套 central + 观测 ACK |
| 绝对发射功率（dBm） | ⚠️ | 仅在一次性黄金校准后达到半绝对（semi-absolute） |
| 频率偏移 / 漂移 | ❌ | 需要 SDR（例如 HackRF）+ 一个受纪律约束的参考源 |
| 调制质量（Δf） | ❌ | 需要 IQ —— 即一台 SDR |
| 邻道功率（深度限值） | ❌ | 需要一台经校准的频谱分析仪 |

## 逐步扩展

要测频率偏移、漂移和调制，需加装一台带 GPS 纪律参考（GPS-disciplined reference）的 SDR；要测经校准的绝对功率和 ACP，需加装一台频谱分析仪。一套实用的产线测试台会组合：一个配套的 nRF central（协议 + 灵敏度）、BLEhound（空口观测 + 基于 ACK 的 PER）、一台 SDR + GPSDO（频率／调制），以及 —— 为了经校准的功率／ACP —— 一台频谱分析仪，全部置于一个屏蔽射频的夹具内，并借助黄金样机做转移校准（transfer calibration）。

!!! note "注意"
    屏蔽外壳和固定夹具必不可少 —— 否则环境中的 2.4 GHz 流量会淹没量测。对于密封设备的绝对辐射指标（TRP/TIS），仍需一个空口（OTA）校准暗室。
